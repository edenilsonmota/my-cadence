# Política de privacidade do My Cadence

*Última atualização: 24 de novembro de 2026*

O My Cadence (nome no aparelho: **Cadence**) é um app pessoal de organização: tarefas, flashcards, pomodoro,
books e agenda. Ele funciona **offline** e guarda tudo no próprio aparelho.

## O que o app guarda e onde

- **No aparelho:** todos os seus dados (tarefas, cards, sessões, páginas e ajustes), num banco local.
- **No seu Google Drive, se você conectar uma conta Google:** uma cópia desses dados para sincronizar entre os
  seus aparelhos. Ela fica na **pasta privada do app** no seu Drive (`appDataFolder`), que só o próprio
  My Cadence enxerga. O app não lê nem altera nenhum outro arquivo do seu Drive.
- **Da sua conta Google** o app usa só o nome, o e-mail e a foto, para mostrar qual conta está conectada.

## O que o app não faz

- Não envia seus dados para servidores do desenvolvedor (não existe servidor do app).
- Não compartilha nem vende dados a terceiros.
- Não tem anúncios, rastreamento nem análise de uso.

O único contato com a internet, além do Google Drive, é a verificação de versão nova, que consulta a página
pública de releases do projeto no GitHub sem enviar nenhum dado seu.

## Como apagar

- **Dados no aparelho:** desinstalar o app ou limpar os dados dele nas configurações do Android.
- **Cópia no Drive:** no Google Drive pela web, Configurações → Gerenciar apps → My Cadence → Opções →
  **Excluir dados ocultos do app**. Para o app não acessar mais o Drive, desconecte a conta no app e remova o
  acesso em <https://myaccount.google.com/permissions>.
